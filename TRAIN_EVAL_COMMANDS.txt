SAM3 LoRA — Cholec + EndoVis + CaDIS
训练 / 测试命令速查
=====================================

工作目录:
  cd /mnt/data2_hdd/changjing/SAM3_LoRA

环境:
  conda activate sam3_lora

配置文件:
  configs/light_lora_config.yaml

训练数据 (合并后):
  /mnt/data2_hdd/changjing/SAM3_LoRA/datasets/surgical_mix_coco_stride5/train
  (1680 images, 40 classes, 各数据集保留原始 prompt)

权重输出:
  outputs/surgical_mix_lora_stride5/best_lora_weights.pt
  outputs/surgical_mix_lora_stride5/last_lora_weights.pt


一、重新合并数据（仅当源 COCO 有更新时）
----------------------------------------
  bash datasets/Endo_VL/merge_surgical_coco.sh

  # 合并后若图片是 NAS 软链，拷到本地盘（训练更快，约 1.2GB）
  bash datasets/materialize_surgical_mix.sh


二、训练
----------------------------------------
  # 单卡 GPU 0
  python train_sam3_lora_native.py --config configs/light_lora_config.yaml

  # 指定 GPU 1
  python train_sam3_lora_native.py --config configs/light_lora_config.yaml --device 1

  # 断点续训（auto_resume: true 时自动读 last_lora_weights.pt + val_stats.json）
  export PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True
  python train_sam3_lora_native.py --config configs/light_lora_config.yaml --device 0

  # 手动指定 epoch（覆盖自动推断）
  python train_sam3_lora_native.py --config configs/light_lora_config.yaml \
    --start_epoch 3

  # 全新训练：config 里 auto_resume: false，或删掉 output_dir 下旧权重


三、测试 / 评测（按数据集分开跑，不要用合并训练集）
----------------------------------------
  WEIGHTS=outputs/surgical_mix_lora_stride5/best_lora_weights.pt
  CONFIG=configs/light_lora_config.yaml
  ENDO_VL=/home/ren7/NAS2/changjing/Endo_VL

  # CholecSeg8K benchmark test (64 images)
  python validate_sam3_lora.py \
    --config ${CONFIG} \
    --weights ${WEIGHTS} \
    --val_data_dir ${ENDO_VL}/cholecseg8k_coco_stride5_benchmark/test

  # EndoVis18 benchmark test (60 images)
  python validate_sam3_lora.py \
    --config ${CONFIG} \
    --weights ${WEIGHTS} \
    --val_data_dir ${ENDO_VL}/endovis18_coco_stride5_benchmark/test

  # CaDISv2 valid (108 images)
  python validate_sam3_lora.py \
    --config ${CONFIG} \
    --weights ${WEIGHTS} \
    --val_data_dir ${ENDO_VL}/cadisv2_coco_stride5/valid

  # CaDISv2 test (118 images)
  python validate_sam3_lora.py \
    --config ${CONFIG} \
    --weights ${WEIGHTS} \
    --val_data_dir ${ENDO_VL}/cadisv2_coco_stride5/test

  # 一次跑完全部 benchmark
  ./run_surgical_mix_train_eval.sh eval-all

  # 调试：只跑前 20 张
  python validate_sam3_lora.py \
    --config ${CONFIG} \
    --weights ${WEIGHTS} \
    --val_data_dir ${ENDO_VL}/cholecseg8k_coco_stride5_benchmark/test \
    --num-samples 20

  # 基线：不加载 LoRA，原始 SAM3
  python validate_sam3_lora.py \
    --use-base-model \
    --val_data_dir ${ENDO_VL}/cholecseg8k_coco_stride5_benchmark/test


四、说明
----------------------------------------
  - 训练用合并集；评测必须用各数据集原始 test/valid（类别 id 与 prompt 与 GT 一致）。
  - 断点续训：auto_resume=true 时自动加载 output_dir/last_lora_weights.pt，并从 val_stats.json 读取已完成 epoch。
  - 全新训练：设 auto_resume: false，或清空/更换 output_dir。
  - 若 best_lora_weights.pt 不存在，把 WEIGHTS 改成 last_lora_weights.pt。
  - 查看完整帮助: ./run_surgical_mix_train_eval.sh help
